# MONOLITH CODES

Software Engineering Studio website built with **React 19**, **Vite 6**, **TypeScript**, and **Tailwind CSS v4**.

## 🚀 Quick Start

```sh
# Install dependencies
npm install

# Start local development server
npm run dev

# Type check
npm run lint

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Custom Tokens
- **Icons & Motion**: Lucide React + Framer Motion
